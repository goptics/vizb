## Capabilities

  ### Tables and benchmarks

CSV and JSON tables, plus Go, Rust, and JavaScript benchmark output. Format is detected from content. See [Supported inputs](/guides/parsers).

  ### Shared dimension model

Name, X, Y, and Z drive every chart type. Group for category breakdowns; select for coordinate plots. See [Dimensions](/getting-started/dimensions).

  ### Self-contained HTML

Interactive UI in one file: sort, swap axes, scale, themes, JPEG export, optional stats. Open it in any browser. See [UI](/ui).

  ### CLI, Action, and API

Local CLI, [GitHub Action](/ci-cd/github-action), and [REST](/commands/serve) for the same pipeline. Merge datasets across runs when you need history.
