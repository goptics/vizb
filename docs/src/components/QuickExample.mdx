Point Vizb at a CSV. Numeric columns become charts. Categorical columns become axes when you group (or when auto-group picks one for you).

After [install](/getting-started/install), chart a table like this:

<SalesSampleCsv />

```bash
vizb bar sales.csv -g region,category -p x,y -o sales.html
```

Open `sales.html` in a browser. You get a grouped bar chart: region on X, category as series, with a chart tab per numeric metric (`quantity`, `amount`).

<DocImage src={bar2D} alt="2D grouped bar chart with category series per region" />

Flags in this example:

- `bar` — one chart type (smallest learning path)
- `sales.csv` — the table above (use **Copy CSV** to grab it)
- `-g region,category` — columns that become dimensions
- `-p x,y` — first group column → X, second → Y series
- `-o sales.html` — self-contained HTML

No `-g`? Vizb auto-groups a high-cardinality categorical column and logs the choice. Override whenever the guess is wrong.

```bash
vizb bar sales.csv -o sales.html
```

From a clone of the Vizb repo, the full sample is `examples/csv/sales.csv` (~500 orders across 2024–2025).
