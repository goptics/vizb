## Capabilities

<CardGrid stagger>
  <Card title="Tables and benchmarks" icon="seti:csv">
    CSV and JSON tables, plus Go, Rust, and JavaScript benchmark output. Format is detected from content. See [Supported inputs](/guides/parsers).
  </Card>
  <Card title="Shared dimension model" icon="list-format">
    Name, X, Y, and Z drive every chart type. Group for category breakdowns; select for coordinate plots. See [Dimensions](/getting-started/dimensions).
  </Card>
  <Card title="Self-contained HTML" icon="laptop">
    Interactive UI in one file: sort, swap axes, scale, themes, JPEG export, optional stats. Open it in any browser. See [UI](/ui).
  </Card>
  <Card title="CLI, Action, and API" icon="seti:puppet">
    Local CLI, composite [GitHub Action](/ci-cd/github-action), and [REST](/commands/serve) for the same pipeline. Merge datasets across runs when you need history.
  </Card>
</CardGrid>
